Python Image Downloader

概要

PythonとTkinterを使用して作成した画像取得・表示アプリケーションです。

WebサイトのURLを指定することで、HTML内のimgタグから画像を取得し、ローカルフォルダに保存できます。

主な機能

Webサイトから画像を取得

すべての画像、または指定件数の画像取得

取得した画像のGUI表示

画像の白黒変換

Next・Backによる画像切り替え

Google・Yahooのブラウザ起動

スクレイピングに関する注意事項の表示

使用技術

Python

Tkinter

Requests

BeautifulSoup4

Pillow

実行方法

必要なライブラリをインストールします。

pip install -r requirements.txt

プログラムを実行します。

python imgcharcter1.py

注意事項

Webサイトの利用規約を確認してから使用してください。

サーバーに過度な負荷をかけないようにしてください。

取得した画像の著作権や利用条件に注意してください。
